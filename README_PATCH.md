# Патч: перемещать файлы только после открытия в браузере или через 5 минут

Заменить метод `move_file` в классе `AppLogic` (файл organizer_gui.py) на код ниже.
Добавлены два правила:
1. Файл не трогается, пока браузер держит его открытым (проверка блокировки).
2. Файл остаётся в «Загрузках», пока:
   а) вы НЕ открыли его из списка загрузок браузера (Ctrl+J), ИЛИ
   б) не прошло 5 минут (grace_seconds = 300) с окончания скачивания.

После применения: python -m py_compile organizer_gui.py
Пересборка: python -m PyInstaller --onefile --noconsole --icon=app.ico organizer_gui.py
